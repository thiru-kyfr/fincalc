# KYFR Tools

31 free Indian financial calculators — SIP, EMI, tax, FD, PPF, and more — built with React, Vite, and Tailwind CSS.

## Categories

- **Investment:** SIP, Lumpsum, SWP, MF Returns, Step Up SIP, CAGR, XIRR, ROI
- **Savings:** SSY, PPF, EPF, FD, RD, NPS, APY, NSC, Post Office MIS, SCSS, Retirement
- **Tax:** Income Tax (FY 2025-26), HRA, TDS, Gratuity, Salary
- **Loans & EMI:** EMI, Car Loan EMI, Home Loan EMI, Simple Interest, Compound Interest, Flat vs Reducing Rate, Inflation

Each calculator uses standard, publicly documented Indian financial formulas.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Outputs a static site to `dist/`, deployable to any static host (Vercel, Netlify, GitHub Pages, etc.).
